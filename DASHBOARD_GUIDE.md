# 🎮 Interactive Dashboard User Guide

## Your Dashboard is Now LIVE!

### 🖱️ **How to Use the Interactive Dashboard**

#### **1. Explore the Charts**

**Hover Over Charts:**
- Move your mouse over ANY chart
- See detailed tooltips with exact numbers
- Watch values highlight as you move

**Zoom Into Data:**
- Click and drag on any chart to zoom
- Double-click to reset zoom
- Use scroll wheel to zoom in/out

**Pan Around:**
- After zooming, click and drag to move around
- Great for exploring monthly trends

#### **2. Save Your Favorite Charts**

**Right-click on any chart:**
- "Download plot as PNG" - Save as image
- "Toggle Spike Lines" - Show crosshairs
- "Reset Axes" - Return to original view

## 🎯 **Common Questions**

**Q: How do I refresh the data?**
A: The dashboard uses static data from the CSV files. To update, regenerate the dashboard with new data.

**Q: Can I print the dashboard?**
A: Yes! Use browser Print function (Ctrl+P) or save as PDF.

**Q: Can I share this?**
A: Yes! Just share the HTML file - it works on any computer with a browser.

**Q: Charts not loading?**
A: Make sure you're connected to the internet (for Plotly library) and using a modern browser.

**Q: How do I export individual charts?**
A: Right-click any chart → "Download plot as PNG"
